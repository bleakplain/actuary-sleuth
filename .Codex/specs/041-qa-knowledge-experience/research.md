# QA 知识库体验研究

核查日期：2026-10-21。仅为计划提供依据；未调用模型、上传资料、读取封存集或修改业务代码。公开事实来自下列第一方来源；“建议”属于本项目待验证的设计判断。

## 1. 已知基线与目标边界

前批候选已修复 24 处表尾问题，v4 含 53 章、1926 块及 1850 个父链接，但最终 9 次开发探针仅 1 次完整解读、3 次原文参考、5 次不可用，出现 5 次 12 秒语义核对超时。全请求终止 P50/P95 为 21.076/43.770 秒，且测试并行影响延迟；这些数据不能外推准确率。候选未激活，53 份来源效力仍未知。来源：[2026-10-21 执行记录](../qa-answer-quality-20261016/execution-report.md)。

ima 官网公开展示多格式导入、基于知识库召回信源及原文溯源；这些是可对齐的产品能力。官网宣传没有给出本项目问题集上的准确率、时延或内部实现，不能据此断言 ima 使用某种知识图谱、校验器或多代理架构。来源：[ima 官方产品页](https://ima.tencent.com/download)（页面未标发布日期，2026-10-21 检索）。

## 2. 短路径优先，复杂问题按需扩展

LangChain 官方将两步 RAG 描述为先检索后生成、模型调用数可封顶，因此延迟通常更可预测；代理检索更灵活，但延迟可变。它也明确既有知识库可以直接接入，无需重建。来源：[Retrieval](https://docs.langchain.com/oss/python/deepagents/retrieval)（2026-10-21 核查）。

建议普通独立问题采用原问检索、结构补全、一次生成的默认路径；只对指代问题改写，对概览、比较或实际缺口启用有界子查询。保留原问与否定、日期、适用对象约束；子查询先并行取证，再统一生成，避免每个子问题都生成一轮答案。最多一次补检索，设置总预算和截止时间。此限制是本项目建议，不能宣称已经提升质量。

LlamaIndex 官方已有子问题拆解和父子层级合并实现，分别适用于跨来源复杂查询和恢复较大上下文。可以复用组件或借鉴算法；自动合并父节点仅是上下文扩展，不证明法律适用关系。计划应先比较现有模块适配成本，无证据支持全栈迁移、全库手工本体或先引入图数据库。来源：[Sub Question Query Engine](https://developers.llamaindex.ai/python/examples/query_engine/sub_question_query_engine/)、[Auto Merging Retriever](https://developers.llamaindex.ai/python/framework/integrations/retrievers/auto_merging_retriever/)（2026-10-21 核查）。

## 3. 引用与核对需要分层

ALCE 论文把流畅度、答案正确性、引用质量分开评估；“有引用”不足以证明答案正确。来源：[Gao 等，EMNLP 2023](https://aclanthology.org/2023.emnlp-main.398/)（2023-12 发表，2026-10-21 核查）。

建议先查引用身份、原文位置、数字/单位、否定与义务强度、显式前提和例外。逐字摘引且结构完整的低推断内容，可以走确定性短路径；涉及跨条归纳、范围扩张、数值推导、效力或冲突的主张，才进入有界语义核对。普通释义不能仅因没有数字就视为低风险。疑点只影响相关主张；独立已支持内容保留，涉及依赖链时整组处理。核对超时属于未完成，不能当作已支持；最终降级应说明缺口并提供定位原文。概览还须独立检查必要维度覆盖，不能以已写出的几条均正确替代整题完整。

## 4. 流畅度必须测到可用正文

智谱官方流式 API 使用 SSE，区分正文增量、思考增量、完成原因和用量。流式传输能力本身不保证答案已获证据支持。来源：[流式消息](https://docs.bigmodel.cn/cn/guide/capabilities/streaming)（2026-10-21 核查）。

建议分别记录首反馈、模型首正文、用户首段可用正文、完整交付及全请求终止时间；成功与失败都进入统计。按问题族报告完整解读率、部分解读率、原文降级率、无证据拒答正确性、危险误答率、校验误拒率、超时率与每题调用数。先用专家确认的开发集做同证据模型对照，再做端到端回放；封存集只用于冻结版本验收。首进度快、mock 通过或检索词项命中均不能替代这些指标。

以下为国内 BigModel 官方按量价目快照，单位均为元/百万 Tokens，列输入/输出价，不含缓存存储等其他费用；不是本账号权益或预算承诺。来源：[API 定价](https://docs.bigmodel.cn/cn/guide/start/pricing)（2026-10-21 核查，实验和发布前须重查）。

| 候选 | 输入 / 输出 | 计划定位 |
| --- | --- | --- |
| `glm-4.7-flash` | 免费 / 免费 | 优先核验的同供应商免费对照候选 |
| `glm-4.7-flashx` | 0.5 / 3 | 付费候选，未调用 |

`glm-4.7-flash` 官方页明确支持流式，示例使用 `stream: true`；《思考模式》说明 GLM-4.7 系列默认开启思考，可以用 `thinking: {"type": "disabled"}` 关闭。因此可将“4.7 Flash、关闭思考、流式”作为免费实验候选，但本轮未实调验证其账号与适配器行为。来源：[4.7 Flash](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)、[思考模式](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)（2026-10-21 核查）。

`glm-5.3-flash` 思考不能关闭，不能凭型号名称推断首字更快；`glm-4.5-flash` 国内文档已公告下线并自动路由到 4.7，不适合作独立比较臂。来源：[5.3 Flash](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)、[4.5 Flash 下线公告](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.5-flash)（2026-10-21 核查）。

执行前须确认实际 endpoint、账号权限/限流、精确模型版本、思考参数是否正确透传、流式终止/用量解析、计费规则及授权预算；新模型和付费实验按后续授权执行。对照必须固定正确证据、问题与输出预算，记录重复运行、超时和费用。现有 `glm-4-flash` 别名的实际路由未经核实；本研究不能证明任何候选在保险产品问答上更准、更快，或足以达到 ima 体验。
